Factory Inventory Management System

A full-stack demo app for inventory, orders, demand forecasting, spending and reporting. A Vue 3 single-page app talks over REST to a FastAPI service that serves in-memory data loaded from JSON files. There is no database.

System architecture

Tech stack

Frontend

Vue 3Composition APIVite Vue Router 4axios

Custom SVG charts and CSS Grid layouts. No UI or charting library. English and Japanese locales.

Backend

Python 3.11+FastAPIUvicornPydantic 2

Handlers filter Python lists in memory and validate responses with Pydantic models.

Data and tooling

JSON filespytestClaude Code agentsMCP

Seed data is produced by generate_data.py. Backend tests live in tests/backend.

Data flow

Four shared filters (Time Period, Warehouse, Category, Order Status) are sent as warehouse, category, status and month. Raw responses are stored in refs and charts and KPIs are derived with computed properties.

Repository map

  • client/src/views/ one file per route
  • client/src/components/ filter bar, detail modals, profile and tasks
  • client/src/composables/ shared filter, i18n and auth state
  • client/src/api.js all backend calls
  • server/main.py routes, models and filter helpers
  • server/mock_data.py JSON loader
  • server/data/ seed data
  • tests/backend/ pytest with FastAPI TestClient
  • .claude/ project agents, commands and skills

Gaps worth knowing

  • Missing backend routes. client/src/api.js calls /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders, but server/main.py defines none of them. This causes the 404 logged on page load.
  • No persistence. Data is read once at startup, so restarting the backend resets everything.
  • Hard-coded API URL. http://localhost:8001/api is set directly in api.js.
